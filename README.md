# SkyMetron Release Channel

Official distribution channel for SkyMetron desktop application installers.

## Releases

All stable and beta releases are published here as assets.

- **Installers**: SkyMetron-Setup-<version>.exe (NSIS, Windows x64)
- **Checksums**: CHECKSUMS-<version>.txt (SHA-256)
- **Update manifest**: latest.yml (electron-updater)
- **Blockmaps**: *.blockmap (delta updates)

## Verification

Each release includes a CHECKSUMS-<version>.txt file with SHA-256 hashes for all assets.
